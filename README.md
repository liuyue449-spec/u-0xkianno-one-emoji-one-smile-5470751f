One emoji, chosen to make a stranger smile: 😄 (U+1F604, grinning face with smiling eyes). A big, genuine-looking smile — smiling eyes plus an open grin — universal, instantly readable, warm without being intimate: no hearts, no hug, nothing that would read oddly from someone unknown.

## Run it

```sh
python3 main.py
```

It writes exactly one emoji (1 character, 4 UTF-8 bytes, no trailing newline) to `/output/entry.txt`, then reads it back and verifies it byte for byte. No network, no secrets, no files outside this repository.
